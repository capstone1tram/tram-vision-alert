## 1. 무엇을 만들었나 (1단계)

트램 위에 단 카메라 한 대로 다음을 순서대로 처리합니다.

```
카메라 ─▶ 선로 검출 ─▶ 위험 구역(트램이 지나갈 자리) ─▶ 사람·차 검출(YOLO11n)
       ─▶ 칼만 필터 추적 ─▶ 거리(궤간 기하) ─▶ TTC·필요 감속도 ─▶ 4단계 등급 ─▶ 경보·화면·기록
```

| 단계 | 방법 | 파일 |
| --- | --- | --- |
| 선로 검출 | 학습 없이 OpenCV: 색·밝기 분리 → 모폴로지 → 줄 단위 스캔 → 직선 맞춤 | `system/tram/rails.py`, `rails_photo.py` |
| 물체 검출 | YOLO11n (COCO 사전학습, 사람·자전거·차·오토바이·버스·트럭) | `system/tram/detectors.py` |
| 추적 | 바닥 평면 등속 선형 칼만 필터, 여러 물체 | `system/tram/kalman.py` |
| 거리 | 두 레일 사이 폭(궤간 1,435 mm)이 화면에서 몇 픽셀인지로 계산, 깊이 카메라 없음 | `system/tram/distance.py`, `ground.py` |
| 위험 판정 | TTC 5초/3초 + 필요 감속도, 위험·경고·주의·안전 4단계, 깜빡임 방지 | `system/tram/risk.py` |
| 연결 끊김 대응 | 0.3초 무응답 → 칼만 예측(불확실성 2σ로 넓힘), 1초 → 파이가 직접 검출 | `system/tram/guard.py`, `link.py` |

**연산 나누기**: 라즈베리파이 5가 촬영·추적·거리·등급·경보를 맡고, 노트북은 무거운 검출만 맡습니다. 노트북이 끊겨도 판단은 파이에 남습니다. 지금은 PC 한 대로 전체를 돌리는 `pc_main.py`도 있습니다.

## 2. 다음 단계로 구상한 방향: 비전 기반 열차 접근 알림

1단계에서 "가까운 물체의 위험 판정"은 됐지만, 실제 현장에서 더 중요한 것은 **멀리 있는 선로 위 사람을 미리 찾아 피하라고 알리는 것**이라는 결론을 냈습니다. 구현하지는 못했고, 이어서 해 볼 사람을 위한 아이디어로 남깁니다.

- **소실점 주변 집중 관찰**: 선로가 모이는 먼 끝(소실점) 주변에 작은 관심 영역(ROI)을 잡아 확대·집중 검출. 멀리 있는 작은 사람도 놓치지 않기.
- **위험 구역 폭 일정하게**: 먼 쪽에서 흔들리던 구역을 카메라 높이·지평선 고정으로 안정화(분석: `docs/analysis/`).
- **중요한 물체 가려내기**: 선로 위·선로로 들어오는 물체와 그렇지 않은 물체 구분.
- **열차 속도 추정**: 영상(바닥 흐름)으로 추정 + IMU 혼합(센서 융합).
- **야간·안개**: 적외선(열화상) 카메라 등 시야가 나쁠 때 쓸 수 있는 센서 조사.
- 할 일: 기존 충돌 예방 장치 조사, 지금 부품으로 작동 가능한지 확인, 실제 카메라로 찍은 영상으로 시험.

**포트폴리오·자소서에 쓰려면**: [`docs/PORTFOLIO_GUIDE.md`](docs/PORTFOLIO_GUIDE.md)에 이력란 문구, 쓸 수 있는 경험, 숫자 쓸 때 주의점, 면접 예상 질문을 정리했습니다.

## 4. 빠르게 돌려 보기 (하드웨어 없이, 노트북 한 대)

```powershell
cd system
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements_laptop.txt
python tools\selftest.py        # "합격"이 나오면 설치 끝
```
